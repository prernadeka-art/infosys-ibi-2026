# Infosys Business Incubator 2026

Scrollable concept experience for Infosys Business Incubator 2026 (May 14, Building 50).

## Scripts

- `npm run dev` - local preview
- `npm run build` - production build
- `npm run assets` - compress deck media into `public/assets`
- `npm run scrub` - fail if banned agency brand strings or em/en dashes appear in source

Set `GITHUB_PAGES=true` for the `/infosys-ibi-2026/` base path.
